# Интерактивные виджеты по математике

Самодостаточные HTML-страницы для встраивания в онлайн-доску (Holst, Miro и т.п.)
через iframe. Используются на занятиях «ДенВал научит!».

## Конструктор графиков

**https://fliegerfaust.github.io/maths-functions/**

Прямая `y = kx + b` и гипербола `y = k/x`, вторая линия для сравнения
и автоматический расчёт точки пересечения.

Настройки передаются через хэш ссылки:

| Параметр | Значения | Что делает |
|---|---|---|
| `mode` | `line` / `hyp` | тип функции |
| `k`, `b` | −10…10, −12…12 | коэффициенты прямой |
| `hk` | −24…24 | числитель гиперболы |
| `k2`, `b2` | — | вторая линия |
| `two` | `1` | включить вторую линию |
| `panel` | `off` | скрыть панель управления |
| `theme` | `light` / `dark` | зафиксировать тему |
| `zoom` | 4…40 | масштаб |

Примеры:

- догонялки — `#mode=line&k=3&b=0&k2=1&b2=6&two=1`
- гипербола без панели — `#mode=hyp&hk=12&panel=off`

Управление: колесо мыши — масштаб, перетаскивание — сдвиг, двойной клик — сброс.
